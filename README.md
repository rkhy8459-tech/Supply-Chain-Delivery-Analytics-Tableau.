## 💡 Key Insights & Business Impact
- Analyzed 180,000+ global orders to identify shipping delays, delivery risks, and profit margins.
- Highlighted high late-delivery risks (95.3%) in First Class shipping mode and top loss-making products.
- Built interactive global maps and KPIs to help optimize logistics decisions.
